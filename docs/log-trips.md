# Log Trips

## Log Trips

Trip logging is the core workflow in MyMileage 🛣️.

Record mileage and fuel data for each trip. MyMileage then calculates distance and fuel efficiency automatically.

### What to record

For each trip, enter the values you have available:

* Start mileage
* End mileage
* Fuel filled

### Draft vs completed trips

* **Draft:** Use this when some trip details are still missing.
* **Completed:** Use this when the trip entry is ready and final.

### Calculations

MyMileage uses the values you enter to calculate:

* Trip distance
* Fuel efficiency

{% hint style="info" %}
Use accurate mileage values for better efficiency tracking.
{% endhint %}

### Best practices

* Log trips soon after driving.
* Double-check odometer values.
* Use drafts if you need to finish an entry later.

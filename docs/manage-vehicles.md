# Manage Vehicles

## Manage Vehicles

Use MyMileage to keep all your vehicles in one place 🚘.

### Add a vehicle

{% stepper %}
{% step %}
### Open your vehicle list

Go to the main vehicle view.
{% endstep %}

{% step %}
### Add a new vehicle

Choose the option to add a vehicle.
{% endstep %}

{% step %}
### Enter vehicle details

Add the available details for your vehicle:

* Make
* Model
* Year
* Fuel type
* Registration number

{% hint style="info" %}
Add complete details when possible. It makes trip records easier to review later.
{% endhint %}
{% endstep %}

{% step %}
### Save your vehicle

Your vehicle will appear in the vehicle overview grid.
{% endstep %}
{% endstepper %}

### Edit a vehicle

Update a vehicle any time if details change.

Common reasons to edit a vehicle:

* Fix incorrect vehicle info
* Update registration details
* Adjust fuel type

### Remove a vehicle

Delete vehicles you no longer need.

{% hint style="warning" %}
Removing a vehicle can affect how you review old trip records. Check your history first.
{% endhint %}

### Tips

* Create a separate profile for each vehicle.
* Keep names and details consistent.
* Review vehicle details before logging trips.

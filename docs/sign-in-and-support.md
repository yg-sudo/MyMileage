# Sign-in and Support

## Sign-in and Support

MyMileage supports multiple ways to sign in 🔐.

### Sign-in options

You can sign in with:

* Google
* Microsoft
* Email
* Phone

{% hint style="info" %}
Phone sign-in is still in progress.
{% endhint %}

### Feedback and help

If you want to suggest improvements or report an issue, use one of these channels:

* Email: [unmesh.ghadi@gmail.com](mailto:unmesh.ghadi@gmail.com)
* GitHub issues: [MyMileage Issues](https://github.com/ygllc/MyMileage/issues)
* YouTrack: [MYMILPUB project](https://ygllc.youtrack.cloud/projects/MYMILPUB)

If your improvements are difficult to implement, please say so in the issue. After reviewing, your issue will be added in our internal Jira project.

### When to use each channel

* Use **email** for direct feedback.
* Use **GitHub** for open issue tracking.
* Use **YouTrack** if that is your preferred project tracker.

### Before reporting an issue

Include useful details when possible:

* What you were trying to do
* What happened instead
* Which sign-in method or feature you used
* Any steps to reproduce the issue

# Trip History and Drafts

## Trip History and Drafts

MyMileage helps you review past trips and unfinished entries 📂.

### Browse trip history

Use trip history to review your records over time.

You can use it to:

* Check completed trips
* Find unfinished draft entries
* Review mileage and fuel usage patterns

### Filter trips

MyMileage supports these filters:

* All trips
* Completed trips
* Draft trips

### Work with drafts

Drafts help when you do not have all trip details yet 📝.

Typical draft workflow:

1. Save the trip with partial data.
2. Return later when you have the missing values.
3. Update the trip.
4. Mark it complete.

### Keep your history useful

* Complete drafts regularly.
* Use accurate trip values.
* Keep vehicle details current.

{% hint style="success" %}
A clean history makes fuel and mileage trends easier to understand.
{% endhint %}

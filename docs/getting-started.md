# Getting Started

## Getting Started

MyMileage helps you track mileage 🚙, fuel usage ⛽, and trip history 📅.

Use this guide to get set up fast and start logging useful data.

### Before you begin

Make sure you have:

* Installed MyMileage
* Signed in with your preferred account
* Basic vehicle details ready

### Quick setup

{% stepper %}
{% step %}
### Install MyMileage

Download the app from Google Play or explore the project on GitHub.
{% endstep %}

{% step %}
### Sign in

Choose one of the supported sign-in methods:

* Google
* Microsoft
* Email
* Phone[^1]
{% endstep %}

{% step %}
### Add your first vehicle

Create a vehicle profile before logging trips.

Add the details you have available, like make, model, year, fuel type, and registration number.
{% endstep %}

{% step %}
### Log your first trip

Enter:

* Start mileage
* End mileage
* Fuel filled

Save the trip as a draft or mark it complete.
{% endstep %}
{% endstepper %}
